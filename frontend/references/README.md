# Frontend references

Эта папка содержит справочные материалы для будущей интеграции внешних UI-компонентов во frontend проекта “Вектор”.

Компоненты и примеры из этой папки **не являются частью production UI** и не должны импортироваться напрямую в реальные страницы приложения.

## Назначение папки

`frontend/references` используется как безопасное место для хранения:

- исходного кода внешних компонентов;
- примеров использования под проект “Вектор”;
- заметок по установке зависимостей;
- инструкций по будущей интеграции;
- рисков для Next.js, SSR, accessibility и производительности.

## Правило интеграции

Компоненты из `references` нельзя подключать напрямую в приложение.

Перед реальным использованием компонент нужно:

1. Перенести в рабочую папку компонентов frontend.
2. Адаптировать под архитектуру проекта.
3. Проверить зависимости.
4. Проверить SSR/client component требования.
5. Запустить проверки frontend.

Рекомендуемые команды:

```bash
npm run lint
npm run typecheck
npm run build

*.source.tsx

Файл с исходным кодом компонента из внешнего источника.

В этом файле допускается минимальная адаптация под Next.js, например:

локальная правка путей импорта стилей.

Нельзя переписывать компонент “по мотивам”, если задача — сохранить официальный код.

Важные ограничения
Не импортировать компоненты напрямую из frontend/references.
Не менять production UI из reference-патчей.
Не менять backend.
Не менять API-контракты.
Не добавлять зависимости без явного решения.
Не использовать брендинг внешних библиотек в пользовательском интерфейсе проекта.
Не хранить секреты, токены или .env-значения в reference-файлах.
